# Java Banking System

A Java-based client-server banking application that uses TCP/IP socket communication to simulate real-world banking operations. The system supports role-based access for managers, tellers, and customers through ATM and teller interfaces.

## Features
- Role-based access control for managers, tellers, and customers
- ATM interface for customer banking transactions
- Teller interface for account operations
- Manager tools for account and PIN creation
- TCP/IP client-server communication
- User authentication and account management
- Deposit, withdrawal, and balance inquiry functionality
- Java Swing graphical user interfaces

## Technologies
- Java
- Java Swing
- TCP/IP Sockets
- Client-Server Architecture
- Object-Oriented Programming
